# Portal Header QA

## Back/Forward Controls
1. Open a staff page (e.g. `/staff/projects`).
2. Navigate Projects → open a Project → open Schedule.
3. Use the header **Back** button:
   - Returns to the previous page.
4. Use the header **Forward** button:
   - Returns forward after a Back.
5. Confirm disabled states:
   - Forward is disabled until you’ve navigated back.
   - Buttons do nothing when disabled.
