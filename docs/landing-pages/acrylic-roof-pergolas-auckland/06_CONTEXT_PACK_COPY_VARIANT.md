## Purpose

This is a second, materially original version of the acrylic roof pergola landing page. It uses `docs/Sanctuary_Pergolas_AI_Copywriting_Context_Pack.md` as the primary source for positioning, tone, customer language and claim boundaries.

The existing canonical page informed only the search intent, topic coverage, verified project set and broad landing-page responsibilities. Its headings, narrative sequence and long-form copy were not used as a writing template.

## Narrative

The variant follows this decision path:

1. Covering the deck also changes the room beside it.
2. Define the everyday outcome before selecting a roof product.
3. Resolve use, daylight, openness and rainwater questions together.
4. Use completed projects as proof beside the design claims.
5. Explain acrylic tints as site-specific trade-offs.
6. Set honest expectations for open edges and optional side protection.
7. Show a consultative path from useful context to an agreed scope.
8. Help customers compare quote scope rather than headline price alone.
9. Ask for one concrete next step: suburb, photos and rough dimensions.

## Claim posture

- No performance percentages, public price, lead-time promise or warranty duration is published.
- Consent, engineering, post placement, spans and house connections remain conditional on the completed site and design assessment.
- Weather language distinguishes overhead rain cover from wind-driven rain through open sides.
- Project facts and imagery come from current repository project records.
- No anonymous customer research is presented as a quotation or testimonial.
- No unresolved placeholder is rendered.

## Publication safety

The review route is intentionally `noindex, nofollow`, uses the production page as its canonical and is excluded from the sitemap. This prevents two near-identical search targets from competing while both versions are available for review.

When this variant is selected, publish the copy at the canonical production route and retain the existing self-referencing canonical and sitemap entry. Do not index both routes. The copy and form integration require no further content placeholders before that swap.
