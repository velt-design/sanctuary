# Rail Components

Portal drawing object-workbench rail components belong here.

`ObjectWorkbenchRail` is the canonical hidden workbench rail. `ConfiguratorRail` remains here for the estimates tab compatibility surface.

House Forms in the hidden object workbench expose all eight preset footprints and the four live house roof forms: flat, mono, gable, and hipped. Preset footprints should keep those roof forms available and non-blocked; unsupported custom topology keeps the roof-form intent selectable while showing the blocking diagnostic.
